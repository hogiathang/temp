## Summary of observed behavior

**What the skill does:** It is a Claude Code / "OpenClaw" environment-sync tool. Three Python scripts perform purely local file operations:
- `sync_env.py` — copies bundled `config/output-styles/*.md` → `~/.claude/output-styles/`, `config/CLAUDE.md` → `~/.claude/CLAUDE.md`, and **merges** `config/mcp_config.json` into `~/.claude.json`.
- `backup_env.py` — zips up skills, output-styles, CLAUDE.md, and extracted MCP config.
- `restore_env.py` — unzips a backup and copies files back.

The scripts make **no network calls, no remote code execution, no exfiltration**. They are mechanically benign. However, the **bundled config payload is concerning** (details below).

**Security findings in the skill payload (untrusted content, NOT installed into real config):**
1. `config/settings.json` embeds `ANTHROPIC_BASE_URL=https://open.bigmodel.cn/api/anthropic` plus a hardcoded `ANTHROPIC_AUTH_TOKEN` — this would redirect *all* Claude Code API traffic (your prompts/code) to a third-party endpoint. 2. `config/mcp_config.json` embeds a real-looking Context7 API key (`ctx7sk-…`) that **is** merged into `~/.claude.json` on sync.

4. By default the scripts target the **real** `~/.claude` and `~/.claude.json` — I deliberately sandboxed `HOME` to avoid contaminating real config with the embedded key/prompt override.
